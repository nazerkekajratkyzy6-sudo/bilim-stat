# BILIM STAT AI — Оқу нәтижелерін зерттеу және болжау зертханасы

Интерактивная математическая лаборатория для научного проекта ученицы 11 класса.

**Тема:** «Математикалық статистика әдістері арқылы оқушылардың оқу нәтижелерін зерттеу және болжау: дисперсия, корреляция және білім сапасын оңтайландыру»
**Секция:** Математика. Қолданбалы математика

Путь исследования: Нақты деректер → Статистикалық талдау → Математикалық модель → Болжам → Дәлдігін тексеру → Практикалық ұсыныстар.

Все расчёты выполняются в браузере. Нет регистрации, сервера, Supabase, Firebase и платных API. Данные хранятся только в браузере пользователя (localStorage).

---

## 1. Быстрый запуск на компьютере

Нужен Node.js 18 или новее (https://nodejs.org).

```bash
npm install        # установить зависимости (один раз)
npm run dev        # запустить: откроется адрес вида http://localhost:5173
npm test           # запустить математические тесты
npm run build      # собрать готовый сайт в папку dist/
npm run preview    # посмотреть собранный сайт
```

После `npm run build` папка `dist/` работает без интернета: её можно открыть через `npm run preview` или любой статический сервер.

## 3. Исходные данные

Стартовые данные находятся в файле `src/data/seed.ts`. Ученики обозначены кодами O01, O02…

**Важно про 9 класс:** максимальные баллы БЖБ 1 и БЖБ 2 не подтверждены, поэтому в файле они равны `null`. Пока их не ввести, баллы 9 класса не переводятся в проценты и не входят в модель — платформа показывает предупреждение и не подставляет выдуманные значения.

### Как изменить данные

**Вариант А — в интерфейсе (рекомендуется).** Раздел «Нақты деректер»:
- выберите класс; в строке «Ең жоғары балл (барлығына)» введите максимум сразу для всех учеников (например, для 9 класса);
- редактируйте баллы прямо в таблице, добавляйте и удаляйте учеников;
- «БЖБ 3 бар» включает третий БЖБ для класса;
- изменения сохраняются в браузере автоматически;
- «Бастапқы деректерге қайтару» возвращает стартовый набор.

**Вариант Б — через Excel.** Нажмите «Импорт үлгісін жүктеу», заполните шаблон и загрузите кнопкой «Excel / CSV импорттау». Колонки:
`Сынып, Оқушы коды, БЖБ 1, БЖБ 1 ең жоғары балл, БЖБ 2, БЖБ 2 ең жоғары балл, БЖБ 3, БЖБ 3 ең жоғары балл, ТЖБ, ТЖБ ең жоғары балл`.
Понимаются и русские названия (Класс, Код, СОР1, СОЧ…), десятичная запятая и CSV с разделителем «;».

**Вариант В — в коде.** Отредактируйте `src/data/seed.ts`, например для 9 класса замените `max: null` на подтверждённый максимум. Чтобы новые стартовые данные появились у пользователя, который уже открывал сайт, нажмите «Бастапқы деректерге қайтару».

## 4. Математика (кратко)

- Баллы переводятся в проценты: `score / max · 100`. Разные максимумы (10, 13, 17, 25…) — не ошибка.
- Дисперсия: переключатель «Таңдамалы s² (n−1)» / «Генералдық σ² (n)». Используемое определение всегда подписано.
- Регрессия: `a = Σ(x−x̄)(y−ȳ) / Σ(x−x̄)²`, `b = ȳ − a·x̄`, `R² = 1 − SSқалд / SSжалпы`.
- Значимость корреляции: `t = r√(n−2) / √(1−r²)`, критические значения Стьюдента при α = 0,05.
- Входной показатель x: первый БЖБ, последний БЖБ или среднее процентов БЖБ.
- **Нет утечки ТЖБ:** прогноз для ученика всегда строится моделью, обученной без него (это проверено тестом).
- Если прогноз выходит за 0–100 %, показываются и исходное значение, и ограниченный практический прогноз.
- Победитель в сравнении методов не задан заранее — он определяется только по рассчитанной MAE.

### Честный результат на стартовых данных

На текущих данных простой метод ŷ = x (ТЖБ % ≈ БЖБ %) даёт меньшую ошибку Leave-One-Out, чем регрессия, в 10, 11 классе и в объединённой выборке (при x = среднее БЖБ). Регрессия значительно точнее прогноза по среднему классу. При x = «последний БЖБ» в 10 классе лучшей оказывается регрессия. Это настоящий научный результат, его стоит обсуждать на защите: при малой выборке (5–7 учеников) коэффициенты регрессии неустойчивы, а простая модель не тратит данные на оценку параметров.

## 5. Тесты

```bash
npm test
```

44 теста: среднее, медиана, мода, обе дисперсии, σ, V, корреляция, t-критерий, регрессия, R², MAE, RMSE, максимальная ошибка, Leave-One-Out, отсутствие утечки ТЖБ, нормализация баллов, пропуски, нулевая дисперсия, граничные значения, импорт Excel/CSV.

Контрольные значения для 10 и 11 классов посчитаны независимо на Python (numpy `polyfit`, `corrcoef`, модуль `statistics`) и совпадают с платформой до 8 знаков после запятой. Файлы тестов: `src/lib/stats.test.ts`, `src/lib/io.test.ts`.

## 6. Загрузка на GitHub

**Без командной строки:**
1. Зайдите на https://github.com → **New repository** → имя, например `bilim-stat` → **Create repository**.
2. На странице репозитория: **uploading an existing file**.
3. Перетащите всё содержимое папки проекта, **кроме** папок `node_modules` и `dist`.
4. Нажмите **Commit changes**.

**Через командную строку:**
```bash
git init
git add .
git commit -m "BILIM STAT"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/bilim-stat.git
git push -u origin main
```

## 7. Публикация на Vercel

1. Зайдите на https://vercel.com и войдите через GitHub.
2. **Add New → Project** → выберите репозиторий `bilim-stat` → **Import**.
3. Настройки определятся автоматически (они также записаны в `vercel.json`):
   - Framework Preset: **Vite**
   - Build Command: `npm run build`
   - Output Directory: `dist`
4. **Deploy**. Через 1–2 минуты появится адрес вида `bilim-stat.vercel.app`.

Переменные окружения не нужны. После каждого изменения на GitHub Vercel пересобирает сайт сам.

## 8. Использование на научной защите

1. **Заранее** (на том компьютере и в том браузере, с которого будет защита) откройте сайт, введите подтверждённые максимумы для 9 класса и проверьте данные. Данные сохраняются в этом браузере.
2. Откройте **«Ғылыми қорғау режимі»** (кнопка внизу меню) → нажмите значок полного экрана.
3. Управление: стрелки ← / → или пробел, точки внизу, кнопки «Артқа / Келесі». Esc — выход.
4. Сверху справа выбирается класс — все графики слайдов 3–9 пересчитываются.
5. **Слайд 6 «Болжам жасау»** — живая демонстрация: выберите ученика, двигайте ползунок БЖБ и покажите, как меняется прогноз. Модель строится без выбранного ученика.
6. На вопросы экспертов удобно отвечать из разделов: «Есептеуді көрсету» раскрывает каждую формулу с подстановкой чисел; «Модель тұрақтылығы» показывает влияние одного ученика.
7. Отчёт: раздел «Зерттеу қорытындысы» → «Басып шығару / PDF» → в окне печати выбрать «Сохранить как PDF».

ФИО ученицы, название школы и руководителя на страницах защиты не выводятся.

## 9. Название

Название задаётся одной строкой в `src/config.ts`:
```ts
export const BRAND_NAME = 'BILIM STAT AI';
```
Прогноз выполняет не нейросеть, а математическая статистика (МНК-регрессия), поэтому для защиты в секции «Қолданбалы математика» точнее подходит **BILIM STAT** — замените строку на `'BILIM STAT'`. Платформа нигде не утверждает, что прогноз делает ИИ.

## 10. Структура проекта

```
src/
  lib/stats.ts        чистые статистические функции
  lib/model.ts        данные, нормализация, LOO, сигналы риска
  lib/report.ts       сборка отчёта из расчётов
  lib/io.ts           импорт/экспорт Excel и CSV
  lib/*.test.ts       математические тесты
  data/seed.ts        стартовые данные
  pages/              разделы платформы
  components/         графики, формулы, элементы интерфейса
  config.ts           название и тема работы
```

Стек: React 18, TypeScript, Vite, Tailwind CSS 4, Recharts, KaTeX, Framer Motion, SheetJS, Vitest. Шрифты (Golos Text, Commissioner) подключены локально и поддерживают казахские буквы.
